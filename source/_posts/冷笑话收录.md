{% fold '什么动物最安静' %}
**大猩猩，因为大猩猩会悄咪咪 (动作)**
{% endfold %}

{% fold '有一个面包走在路上，脚扭了，他变成了什么' %}
**牛角包**
{% endfold %}

{% fold '有一个女生叫莉莉，她唱歌很难听，但为什么一出去旅游就变好听了' %}
**因为他变成了游客莉莉（尤克里里）**
{% endfold %}

{% fold '什么动物要小心地滑' %}
**狐狸，狐狸很狡猾 (脚滑)**
{% endfold %}

{% fold '吸血鬼碰到热血青年会怎么样' %}
**会被烫的满嘴起泡**
{% endfold %}

{% fold '谁一说话就飘出口臭味' %}
**初音未来 (出音味来)**
{% endfold %}

{% fold '为什么超人要穿紧身衣' %}
**因为救人要紧**
{% endfold %}

{% fold '茉莉花、玫瑰花、太阳花那个力气最小' %}
**茉莉花，好一朵美丽(没力)滴茉莉花~**
{% endfold %}

{% fold '擎天柱被威震天拆成了零件，大黄蜂抱着零件去找救护车，救护车指着零件问：这是啥?' %}
**你若安好，便是擎天**
{% endfold %}

{% fold '三国的时候谁经常被奶奶扇巴掌' %}
**赵云，因为吾乃常山赵子龙**
{% endfold %}

{% fold '为什么房子是立方体却按平方买钱' %}
**因为二次元的钱真好赚**
{% endfold %}

{% fold '宇航员为什么使用Linux' %}
**因为太空中无法打开Windows（窗）**
{% endfold %}

{% fold '为什么机械硬盘不能进皇宫' %}
**因为机械硬盘怕震（朕）**
{% endfold %}

{% fold '为什么华为公司着火，警察和消防都来了，但是余承东不让消防进去' %}
**因为 遥遥领（110）先**
{% endfold %}

{% fold '为什么蘑菇向橙子说去死，橙子就去死了' %}
**君（菌）要臣（橙）死，臣不得不死**
{% endfold %}

{% fold '吸血鬼为什么怕大蒜' %}
**因为他只能吃 Blood (不辣的)**
{% endfold %}

{% fold '砍树的时候为什么会累' %}
**累，因为伐木累 (Family)**
{% endfold %}

{% fold '为什么有 Win7、Win8、Win10，没有 Win9' %}
**因为 Win9（温酒）斩华雄去了**
{% endfold %}

{% fold '国有国法家有家规，动物园有什么' %}
**有乌龟（规）**
{% endfold %}

{% fold '小红和朋友围在一起讲故事，为什么小红讲完一个故事后周围都没有人了' %}
**因为她讲了一个感人（赶人）的故事**
{% endfold %}

{% fold '为什么羊被剃了毛就睡不着了' %}
**因为它失眠（棉）了**
{% endfold %}

{% fold '什么地方的电话打不通' %}
**宁波（您拨）打的电话无法接通**
{% endfold %}

{% fold '哪种小动物最辛苦' %}
**蚂蚁，因为他们是蚁（乙）方**
{% endfold %}

{% fold '什么水果最适合在银行上班' %}
**桂圆（柜员）**
{% endfold %}

{% fold '餐厅里谁最厉害' %}
**客人，因为他有点东西**
{% endfold %}

{% fold '课堂上老师让小猫小狗小猪背课文，谁先背' %}
**小狗先背，旺旺仙贝（先背）**
